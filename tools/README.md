# tools

Конвертация отсканированных книг (PDF) в Markdown.

## Структура папок

```
books/
├── raw/         оригиналы (PDF) — ничего не меняем
├── processed/   зеркало raw/: на каждый файл своя папка с .md и images/
├── bench/       25 страниц для сравнения движков + их результаты
└── tools/       код обработки (эта папка)
    └── vast/    аренда GPU на vast.ai + PaddleOCR-VL
```

## Три пути обработки

| путь | код | стоимость 539 страниц | когда |
|---|---|---|---|
| OCR-слой из PDF | `pdf_to_markdown.py` | бесплатно | скан уже с текстовым слоем |
| Mistral OCR 4 | `mistral_ocr.py` | $2.16 | ничего не настраивать, но файл до 50 МБ |
| PaddleOCR-VL на аренде | `vast/launch.py` | ~$0.10 | лучшее качество за минимальные деньги |

Сравнение движков на одних и тех же 25 страницах лежит в `bench/`.

Имя папки в `processed/` совпадает с именем файла в `raw/` без расширения —
`raw/some_book.pdf` → `processed/some_book/some_book.md` + `processed/some_book/images/`.

## Установка

```bash
python3 -m venv tools/venv
tools/venv/bin/pip install -r tools/requirements.txt
```

## Запуск

```bash
tools/venv/bin/python tools/pdf_to_markdown.py raw/some_book.pdf
tools/venv/bin/python tools/pdf_to_markdown.py raw/some_book.pdf --no-images   # только текст
FIRST=30 LAST=48 tools/venv/bin/python tools/pdf_to_markdown.py raw/some_book.pdf  # диапазон страниц, для отладки
```

Второй позиционный аргумент — своя папка вывода, если нужна не `processed/<имя>`.

## Что делает скрипт

Сканы Internet Archive уже содержат OCR-слой, поэтому распознавание не запускается —
берётся готовый текст, а работа идёт над версткой:

- **две колонки** читаются в правильном порядке; центрированные шапки страниц
  (номер и название главы), которые пересекают межколонник, не разрываются пополам;
- **абзацы**, разрезанные OCR, склеиваются обратно — в том числе через границу
  страницы; переносы со знаком `-`/`¬` убираются;
- `Chapter N` и `Sec. N.M` становятся заголовками Markdown; названия глав берутся
  из оглавления книги (крупный шрифт на шмуцтитулах распознаётся хуже);
- подписи `Fig. / PLATE / Table` выделяются курсивом;
- колонцифры убираются из текста и сохраняются в комментариях
  `<!-- pdf page N | printed page M -->` — по ним легко вернуться к скану;
- **иллюстрации**: страница скана — одна цельная картинка (MRC), вытащить рисунки
  как отдельные изображения нельзя, поэтому пустые полосы между строками текста
  рендерятся в PNG (150 dpi) и вставляются в текст на своё место. Почти белые
  вырезки отбрасываются.

## Настройка под другую книгу

Константы вверху `pdf_to_markdown.py` подобраны под страницу ~506×733 pt:
`FIG_MIN_H` (минимальная высота полосы, считающейся рисунком), `FIG_DPI`,
`WIDE_FRAC` (доля ширины страницы, при которой строка считается идущей через обе
колонки), `TOP_MARGIN`/`BOT_MARGIN`. Межколонник берётся как середина страницы.
Для однокколоночной книги ничего менять не нужно — разметка определяется
автоматически по страницам.

Отлаживать удобно на коротком диапазоне через `FIRST`/`LAST`.

## Качество

Текст воспроизводится как есть из OCR-слоя, поэтому опечатки распознавания
остаются (например, `SCRAPIJvfG` вместо `SCRAPING` в крупных заголовках).
Автозамены сделаны только безопасные: кавычки, мягкие переносы, пробелы перед
знаками препинания. Если понадобится более чистый текст — нужен повторный OCR
(`ocrmypdf --redo-ocr` + tesseract), это отдельный проход.
